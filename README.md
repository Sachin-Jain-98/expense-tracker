# Expense Tracker

Personal finance application for tracking expenses, setting budgets, and generating spending reports.

## Tech Stack
- React + Vite (frontend)
- Node.js + Express (backend)
- In-memory data store

## Features
- Add and track expenses
- Set category budgets
- View spending summary with charts
- Delete expenses

## Run Locally

### Backend
```bash
cd server
npm install
npm start
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Then open http://localhost:3001
